# 📚 BOOK-CRUD-FASTAPI

A simple Book Management REST API built using **FastAPI, Python, SQLModel and PostgreSQL**.

This project demonstrates CRUD operations for managing books.

## 🚀 Features

- Create a new book
- Get all books
- Get a book by ID
- Update book details
- Delete a book
- PostgreSQL database connection
- FastAPI automatic API documentation

## 🛠️ Technologies Used

- Python
- FastAPI
- SQLModel
- PostgreSQL
- Uvicorn
- VS Code
